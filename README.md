## 🚀 Overview

**Calc-It-Out** is a simple yet effective terminal-based calculator. Designed as a foundational programming project, it efficiently handles basic arithmetic operations using clean and readable C code.

### ✨ Features
* ➕ **Addition** 
* ➖ **Subtraction**
* ✖️ **Multiplication**
* ➗ **Division**
* 🛡️ **Error Handling:** Gracefully handles invalid operators and prevents program crashes.
* 🎯 **Precision:** Returns calculations accurate to 2 decimal places.

## 💻 How to Run

It takes just a few seconds to compile and run this project on your machine!

### 1. Compile the Code
Open your terminal and use the GCC compiler:
```bash
gcc -o calc Calc-It-Out.c
```

### 2. Execute the Program
**Windows:**
```bash
calc.exe
```
**Linux / macOS:**
```bash
./calc
```

### 3. Usage Example
```text
Enter an operator (+, -, *, /): *
Enter two operands: 12.5 4
Result: 50.00
```
